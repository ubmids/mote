# registry/apartment.txt — the commands an apartment answers to, and the ways
# people actually ask for them.
#
# Format: a line "[id]" opens a command; every non-blank line after it is one
# phrasing. Blank lines and lines starting with # are ignored. Nothing else is
# syntax, because this file is meant to be edited by whoever lives here, not by
# whoever wrote the parser.
#
# tools/intent_build compiles this into vectors once; the device then matches
# against them with a single forward pass per utterance and no generation at
# all. Which means the only thing that changes behaviour here is the wording
# below, so write it the way it is said out loud: short, clipped, half a
# sentence, complaining about the room rather than naming the device.
